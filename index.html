      iPhone doesn't let websites join the Share menu, so we add a small Shortcut that does the upload. You set it up once, in about 5 minutes.

      1. Open the Shortcuts app, tap +, name it Save to DocSync.
      2. Tap the ⓘ (or the name at the top), turn on Show in Share Sheet. Set it to receive Files, Images and PDFs.
      3. Add Repeat with Each item in Shortcut Input. Put steps 4 to 9 inside the loop.
      4. Add Get Details of Files: Name of Repeat Item. Add it again for File Extension.
      5. Add Text: Name.File Extension (tap to insert both variables, with a dot between).
      6. Add URL Encode the Text. Add Base64 Encode the Repeat Item, and set Line Breaks to None.
      7. Add Get Contents of URL. URL: the first value below, then tap to insert URL Encoded Text at the end. Method: PUT.
      8. Headers: Authorization = the second value below. Request Body: JSON with two Text fields: message = Upload Text [iPhone, share] (insert the Text variable) and content = Base64 Encoded.
      9. Add Show Notification: Saved to DocSync.

      This is your access key. Anyone with it can read your documents. Paste it only into the Shortcut.

      Then in any app (Files, Photos, Mail, WhatsApp) tap Share, then Save to DocSync. On an iPad, write iPad instead of iPhone in the message. Full guide: docs/IOS_SHORTCUT.md in the repo.
